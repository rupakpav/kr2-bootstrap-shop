## Описание

Периферия — учебный многостраничный магазин компьютерных аксессуаров. Базовая структура выполнена в практических работах №9–10, самостоятельные доработки добавлены по требованиям №11.

В каталоге девять учебных моделей: три клавиатуры, три мыши и три модели наушников. Цены, характеристики, контакты и условия получения демонстрационные. Backend отсутствует: формы не отправляют и не сохраняют контактные данные.

## Запуск

Откройте index.html в браузере или запустите проект через Live Server в VS Code. Установка npm-пакетов и сборка не требуются. Страницы открываются напрямую через file://; все ресурсы локальные, поэтому интернет для работы сайта не нужен.

Bootstrap 5.3.8 подключён локально: стили — vendor/bootstrap/css/bootstrap.min.css, интерактивные компоненты — vendor/bootstrap/js/bootstrap.bundle.min.js. Собственный css/custom.css подключён после Bootstrap. Лицензия сохранена в vendor/bootstrap/LICENSE.

## Структура проекта

- index.html — главная страница, ссылки на категории, популярные модели и быстрая заявка;
- catalog.html — девять карточек в трёх вкладках и быстрая заявка;
- product.html — общая страница подробного описания выбранной модели;
- order.html — полная форма заявки с выбором одного из девяти товаров;
- contacts.html — условия доставки, самовывоз и контакты;
- css/custom.css — небольшие дополнения к Bootstrap, палитра и положение футера;
- js/shop.js — данные моделей и связь каталога, страницы товара и форм;
- vendor/bootstrap/ — локальный Bootstrap и лицензия;
- images/ — исходная папка для изображений; пока используются временные блоки;
- README.md — описание проекта;
- .gitignore — файл исключений Git.

## Доработки по практической работе 11

### Категории и расширенный каталог

В каталоге девять разных моделей. Клавиатуры, мыши и наушники разделены на три Bootstrap-вкладки. Каждая вкладка содержит три карточки; набор карточек не дублируется. Переключение выполняет компонент Bootstrap Tab через data-bs-toggle="tab". У вкладок есть role, aria-controls и aria-selected.

Карточки используют card h-100 и flex-структуру: цена и кнопки располагаются внизу. На узком экране отображается одна карточка в строке, с 768 px — две, с 992 px — три.

### Связь каталога, товара и заявки

У каждой модели есть постоянный id. Например, кнопка «Подробнее» у компактной клавиатуры ведёт на product.html?product=keyboard-compact.

js/shop.js читает параметр через URLSearchParams и ищет id в заранее заданном списке моделей. Найденная модель определяет название страницы, заголовок, цену, описание, badge и таблицу характеристик. URL не используется как HTML: текст вставляется через textContent.

Кнопка «Оформить заявку» ведёт на order.html?product=keyboard-compact. На странице заявки скрипт выбирает соответствующую option. Кнопка «Очистить» очищает контактные данные, сохраняя исходный товар из ссылки.

Кнопка «Заказать» содержит data-product. Событие show.bs.modal передаёт нажатую кнопку в event.relatedTarget: скрипт берёт id, очищает предыдущие контакты и выбирает нужную модель. Ссылка «Перейти к полной форме заявки» также переносит текущий выбор, в том числе после изменения товара вручную.

Если открыть product.html без параметра, показывается первая модель. Неизвестный id не вызывает ошибку: показываются первая модель и пояснение. При неизвестном id в форме сохраняется пункт «Выберите товар».

Ссылки на категории имеют вид catalog.html#mice-pane. При таком переходе скрипт открывает соответствующую вкладку, поэтому с товара можно вернуться к его категории.

### Доставка и контакты

Добавлена contacts.html. На ней показаны самовывоз, пример курьерского тарифа и срока, порядок подготовки заявки, почта shop@example.com и часы консультаций. В интерфейсе используются тексты магазина без учебных пометок. Страница доступна из общей навигации, подвала и FAQ товара.

### Палитра

В custom.css настроены тёмный зелёно-серый цвет навигации и подвала, бирюзовый основной акцент и светлый фон. Основные значения: #17332f, #176b63, #f4f8f7. Переопределены CSS-переменные Bootstrap и состояния кнопок, вкладок, accordion и фокуса полей. Исходные стили библиотеки не переписываются; Bootstrap по-прежнему отвечает за сетки и компоненты.

Футер остаётся снизу: body — вертикальный flex-контейнер с min-height: 100vh, main занимает свободное место через flex: 1 0 auto.

## Как проверить

1. Открыть все пять страниц и проверить общую навигацию, активные пункты, подвал и мобильное меню.
2. В каталоге переключить все три вкладки. Проверить, что в каждой три модели.
3. У каждой модели открыть «Подробнее» и сверить название, цену, описание и характеристики.
4. Перейти к заявке с товара и проверить выбранную модель. Очистить форму: контакты должны очиститься, исходная модель — остаться выбранной.
5. Открыть быструю заявку из разных карточек. Проверить выбранный товар, закрытие окна и отсутствие прежних контактных данных при новом открытии.
6. В модальном окне изменить товар и перейти по ссылке к полной форме. Выбранная модель должна сохраниться.
7. Открыть категорию с главной страницы и через «Назад в каталог» с товара: должна открыться нужная вкладка.
8. Проверить FAQ, страницу доставки и контактов, обязательные поля и очистку формы.
9. Повторить проверку на ширинах 375, 768, 1024 и 1440 px. Не должно быть горизонтального переполнения или перекрытия контента футером.
10. Отключить интернет и обновить страницы: стили, вкладки, меню, modal и выбор товара должны работать. Проверить консоль браузера.
