# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Студент: Рупаков Павел
Группа: ЭФБО-03-25

## Описание

Учебный интернет-магазин на Bootstrap. Выполнены базовые требования практических занятий №9–11 для КР №2.

## Запуск и подключение Bootstrap

Откройте index.html в браузере. Bootstrap 5.3.8 CSS и JS Bundle подключены через CDN на всех страницах; для их загрузки нужен интернет. Собственный css/custom.css подключён после Bootstrap.

## Практическая работа 9

Созданы шапка, навигация, hero-блок, преимущества, сетка популярных товаров и подвал. Используются container, row, col-12, col-md-*, col-lg-*, g-* и utility-классы отступов.

## Практическая работа 10

Созданы каталог, страница товара и форма заявки. На всех страницах единая навигация с активным пунктом меню. Использованы navbar, dropdown, card, btn, badge, alert, modal, form-control, form-select, input-group, form-check, accordion, breadcrumb и адаптивная таблица.

Форма заявки содержит имя, e-mail, телефон, выбор товара, комментарий и согласие. В каталоге доступна быстрая заявка в модальном окне. Обязательные поля проверяются браузером. Формы учебные: серверная отправка не реализуется в этих заданиях.

## Структура проекта

- index.html — главная страница;
- catalog.html — каталог и модальное окно;
- product.html — товар, характеристики и accordion;
- order.html — форма заявки;
- css/custom.css — минимальные дополнительные стили;
- images/ — папка для изображений; в базовом варианте используются временные блоки;
- README.md — описание проекта;
- .gitignore — файл исключений Git.

## Проверка

Откройте все четыре страницы. Проверьте ссылки, активный пункт меню, dropdown, мобильное меню, открытие и закрытие modal, раскрытие accordion, обязательные поля и очистку формы. Проверьте сетки, таблицу, кнопки и форму на ширинах 375, 768, 1024 и 1440 px. В консоли не должно быть ошибок загрузки Bootstrap.

## Практическая работа 11

Проект подготовлен к локальной проверке КР №2. Работа с GitHub выполняется отдельно владельцем проекта. КР №3 по заданию выполняется в отдельном репозитории на основе КР №1.
